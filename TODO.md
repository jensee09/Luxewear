Implement `/`, `/shop`, `/product/:id`, `/wishlist`, `/cart`, `/checkout`, `/order-success/:id`, and `/account`. Apply Royal Orchid `#8E1EA2`, Orchid Pink `#C654C3`, Candy Blossom `#ED96D7`, Petal Blush `#FFC0DE`, Plum Ink `#2B0A35`, Midnight Plum `#1A0620`, and Blush White `#FFF4FA`, with Playfair Display headings and Inter body type, glass/glowing surfaces, accessible contrast, keyboard focus, reduced-motion behavior, lazy-loaded optimized images, and responsive layouts from 320px to 1920px.
- [x] **Immersive home page** — Include an announcement marquee; glass navigation with cart and wishlist badges; animated mesh-gradient hero with real fashion photography; four category tiles; a rotating 3D collection ring; scroll-parallax editorial story; featured product grid; offer banner; review cards; newsletter; footer; and responsive mobile bottom navigation / desktop dock.
- [x] **Shop and product-detail journey** — Use local JSON product data. `/shop` supports keyword search, category/product filters, sorting, responsive cards, animated browse interactions, and clear empty states. `/product/:id` displays the selected representative photo first, category-curated editorial styling frames, product details, selectable size/colour, quantity controls, size guide, related products, and add-to-cart/wishlist actions.
- [x] **Persistent wishlist and cart** — Persist saved products, badge counts, item removal, and movement into cart. Persist cart lines, quantity/removal controls, and promo code `DEMO10` for 10% off. Charge free shipping only when the merchandise subtotal is above ₹999; otherwise charge ₹79. Charge ₹49 for cash on delivery and show transparent totals.
- [x] **Validated COD checkout and confirmation** — `/checkout` validates delivery details including a 10-digit mobile number and 6-digit PIN, shows the order summary, and offers cash on delivery as the only payment option. Place orders locally in browser storage with an order ID and estimated arrival. `/order-success/:id` shows confirmation, ETA, celebration, and next-step navigation; it does not collect payment.
- [x] **Local account and order history** — `/account` provides a mock local profile, editable details, checkout-created order history, and a four-step status: Order placed, Getting ready, On the way, With you.
- [x] **Real apparel imagery, animation, and demo boundary** — Use 13 real Pexels/Unsplash clothing and lifestyle photographs, optimized as WebP at no more than 150 KB per local source image. Use smooth Motion reveals, 3D tilt/parallax, animated backgrounds, reduced-motion support, and touch-friendly responsive controls. Keep product data in local JSON and state in browser storage; do not add a backend, real authentication, inventory system, or online payment gateway. The current stock-photo source-page licenses and photographer credits still require verification before commercial use.
